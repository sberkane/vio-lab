# Visual–inertial odometry lab

[Open the interactive lab](https://sberkane.github.io/vio-lab/)

Explore 54 precomputed conditions for a geometric observer driven by direct optical flow. Select the trajectory, landmark count, noise level, and available trial to inspect motion estimates, error histories, and recovery from initial errors.

The controls replay saved numerical results; they do not run a new simulation. Shaded bands show empirical trial percentiles where repeated trials are available. Expand the settings for the motion, scene, sensor model, initialization, and gains.

This repository contains only the browser viewer, playback data, numerical checks, and downloadable vector figures. Python simulation programs, private trial arrays, and manuscript files are not included.
